# java-lotto-precourse

## 기능

- 구입 금액을 입력
- 구입 금액에 맞게 로또를 발행
- 각 로또는 1~45 사이의 중복되지 않은 숫자 6개로 구성
- 당첨 번호 6개와 보너스 번호 1개를 입력
- 각 로또와 당첨 번호를 비교해 일치한 개수에 따라 등수를 계산
- 총 수익률을 계산해 출력

---

## 사용 방법

1. 구입 금액을 입력
2. 당첨 번호 6개를 입력
3. 보너스 번호 1개를 입력

---

## 입력 예시

```
구입금액을 입력해 주세요.
8000

당첨 번호를 입력해 주세요.
8, 21, 23, 41, 42, 43

보너스 번호를 입력해 주세요.
7
```

---

## 출력 예시

```
8개를 구매했습니다.
[8, 21, 23, 41, 42, 43]
[3, 5, 11, 16, 32, 38]
[7, 11, 16, 35, 36, 44]
[1, 8, 11, 31, 41, 42]
[13, 14, 16, 38, 42, 45]
[7, 11, 30, 40, 42, 43]
[2, 13, 22, 32, 38, 45]
[1, 3, 5, 14, 22, 45]

당첨 통계
---
3개 일치 (5,000원) - 1개
4개 일치 (50,000원) - 0개
5개 일치 (1,500,000원) - 0개
5개 + 보너스 번호 일치 (30,000,000원) - 0개
6개 일치 (2,000,000,000원) - 0개

총 수익률은 62.5%입니다.
```
